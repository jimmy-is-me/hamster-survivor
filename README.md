# 塔塔醬大冒險

以塔塔醬世界觀全面更新的 HTML5 Canvas 生存冒險。保留移動、武器自動攻擊、升級三選一、成就、三分鐘生存及無盡接關玩法。

- 八個角色：塔塔醬、比偷、卡薰、愛神丘比偷，以及探險、魔法、雨天、花園四個新造型。四位原作夥伴可直接選用，造型依成就解鎖。
- 20 個手繪怪物外觀按戰鬥階段輪替；草帽、魔女、南瓜塔塔擔任三位首領。
- 武器、被動及裝備改為花瓣、星星、塔可與獨角仙主題。角色和怪物使用圖片，取代原本的動物／甜點 Emoji。
- 網頁標題、標誌、瀏覽器 favicon、手機主畫面圖示及 manifest 已更新。原本 hs_save2 成就存檔仍可沿用。

## 操作
WASD／方向鍵移動；選單方向鍵選角色／武器、D 切難度、Enter 開始。升級 1～3、R 重抽。Q/E 調倍速，P 暫停，M 靜音，F 全螢幕。手機使用下方搖桿。

## 本機與檢查
執行 npm install，npm start 後開啟 http://127.0.0.1:4188 。另開終端執行 npm test；使用 Google Chrome 檢查 320、390、768、1440 寬度的選單、素材、移動、怪物、首領、升級、暫停、接關及執行錯誤。自動測試會加速建立測試戰況，不代表已完成長時間無盡平衡測試。

## 部署與素材
將根目錄 HTML、JS、CSS、manifest 與 assets 目錄發布至既有靜態主機，不需建置。推送 GitHub 不代表外部主機已完成部署。儲存庫網址保留 hamster-survivor，遊戲顯示名稱為塔塔醬大冒險。

原作：@tatajiangg；依使用者提供的素材與授權延伸。沿用本對話先前產出的角色、怪物、道具及首領圖，另以內建 ImageGen 生成四款服裝和冒險封面，紀錄見 ARTWORK.md。

## 1.1 動作與養成
- 行走：擺腿、軀幹傾斜與重心起伏；攻擊：手臂揮擊、武器弧線與後座動作；受擊：角色和怪物壓縮晃動。攻擊動作由實際戰鬥事件觸發。
- 移除畫面中的 Emoji：原符號特效改用手繪素材，介面與數值使用文字標籤。
- 花幣：每輪結算取得「本輪擊退數 × 2 + 本輪存活秒數 / 10 向下取整 + 通關 100」。無盡接關按增量計算，防止重複領取。
- 永久養成：體能每級 +10 元氣、傷害每級 +4%、移速每級 +2%，各 10 級；花費為 60 + 當前等級 × 40。保存在 tata_growth_v1，不影響舊 hs_save2 成就。
- 17 張成就卡：達成後一次領取 40 花幣，可裝備一張獲得元氣、傷害或移速加成，下一次出發生效。
- 展開左側角色數據查看血量、傷害倍率、移速、暴擊、減傷、冷卻、回血與吸取範圍。
- 結算顯示冒險累計的有效傷害（不計過量傷害）、最大單次傷害、暴擊／命中次數、承傷、補給回血、首領數、花幣和裝備。
- 可愛傷害數字採原創粉橘／薄荷藍配色、雙描邊、彈跳及錯層顯示，未使用其他遊戲字體或素材。

新增 check-growth.cjs 驗證養成存檔、實際加成、單次領獎、動作狀態、暴擊數字及結算防重複。npm test 會執行兩組測試。
