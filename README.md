# 🐹 倉鼠球大冒險 Hamster Survivor

可愛風單指割草 Roguelike(HTML5 Canvas,純靜態,無需建置)。

## 檔案結構
- `index.html`:頁面與選單結構
- `style.css`:樣式(含電腦版全螢幕版型)
- `game.js`:遊戲邏輯

## 內容
- 8 位角色、9 種武器 + 6 種被動,升級三選一
- 3 場 Boss 戰:60 秒巨無霸甜甜圈、120 秒蛋糕女王、170 秒草莓聖代(三階段)
- 10 種小怪:布丁、甜甜圈、棉花糖、🍡麻糬坦克、🍧刨冰(死後分裂)、🍫巧克力衝鋒、🍒櫻桃炸彈、🍰蛋糕法師(三連發)、🥠幸運餅乾(逃跑型,必掉道具)、🧊冰塊
- 特殊掉落物:💖愛心、🧲全場磁鐵、💣炸彈、❄️冰凍、🛡️無敵、⭐超級經驗、🎁Boss 寶箱
- 加速器:x1 / x1.2 / x1.5 / x2 / x2.5 / x3(右上角按鈕或 Q/E 鍵,會記住上次設定)

## 操作
- 手機:按住畫面下方 20% 拖曳。
- 電腦(自動偵測,全螢幕版型):WASD / 方向鍵移動;選角畫面用滑鼠點選,或 ←→ 換角色、↑↓ 換武器、Enter 開始;升級時滑鼠點卡片或按 1/2/3;Q/E 調整速度、P 暫停、F 切換瀏覽器全螢幕。

## 部署
直接部署到 Cloudflare Pages 或 GitHub Pages(根目錄即可)。
