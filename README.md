# 倉鼠球大冒險 v8

純靜態 HTML5 Canvas 遊戲。保留 v7 核心 game.js / style.css，入口依序載入 v8.js / v8.css 擴充。

## v8
- 通關後按「繼續」：簡單 → 普通 → 困難 → 無盡+1、+2……；保留等級、武器、被動、裝備、復活次數與經驗。
- 換輪清理戰場，回復最大血量的 50%，取得 3 秒護盾及一次免費天賦。無盡每輪以困難為基準額外增加 25% 血量／傷害，出怪加快。
- 升級改為 3 選 1，可重抽；優先包含武器、被動、裝備，重抽盡量避開前次卡片。
- 經驗需求改為 floor(8 + 5*(Lv-1) + 0.35*(Lv-1)^2)。
- 新武器：棉花糖龍捲風、刀叉旋舞、流星糖雨；新被動：精準瞄具；新裝備：吸力手套、守護徽章、甜點皇冠。
- 流星糖雨需通關解鎖，皇冠需擊敗聖代解鎖；新增無盡挑戰者成就。沿用 hs_save2 存檔，不清除既有成就。
- 桌機升級卡片橫向排列，窄螢幕改直列；選單可捲動、文字不壓縮，按鈕與說明分開。

## 操作
WASD／方向鍵移動；選單方向鍵選角色／武器、D 切難度；Enter 開始。升級 1～3、R 重抽。Q/E 調倍速，P 暫停，M 靜音，F 全螢幕。手機使用下方搖桿。
