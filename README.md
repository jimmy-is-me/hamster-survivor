# 🐹 倉鼠球大冒險 Hamster Survivor

可愛風單指割草 Roguelike(HTML5 Canvas,純靜態,無需建置)。

## 檔案結構
- `index.html`:頁面與選單結構
- `style.css`:樣式(含電腦版全螢幕版型)
- `game.js`:遊戲邏輯(頂部 `BAL` 與 `DIFFS` 可直接調整難度與平衡)

## 內容
- 8 位角色、11 種武器、8 種被動、7 種裝備,升級三選一(盡量同時出現武器/被動/裝備,每局有重抽次數,每 5 級 +1)
- 三段難度:簡單 / 普通 / 困難(選角畫面選擇,會記住)
- 血條制:各角色有不同血量,小怪傷害隨時間成長;安全帽可減傷,復活護符可復活
- 3 場 Boss 戰:60 秒巨無霸甜甜圈、120 秒蛋糕女王、170 秒草莓聖代(三階段);擊敗後掉落寶箱(優先給裝備)
- 10 種小怪:布丁、甜甜圈、棉花糖、麻糬坦克、刨冰(分裂)、巧克力衝鋒、櫻桃炸彈、蛋糕法師、幸運餅乾、冰塊
- 特殊道具:💖愛心、🍗烤雞腿、🧲全場磁鐵、💣炸彈、❄️冰凍、🛡️無敵、⭐超級經驗、⏳時間緩速、⚡狂暴
- 音效與背景音樂:全部由 WebAudio 即時合成,不需音檔;Boss 出現時 BGM 會切換為緊張版本;M 鍵或右上角按鈕可靜音
- 成就系統(16 項)與解鎖:部分角色、武器、裝備需達成成就才會解鎖,進度存在瀏覽器 localStorage
- 加速器:x1 / x1.2 / x1.5 / x2 / x2.5 / x3(按鈕或 Q/E 鍵)

## 操作
- 手機:按住畫面下方 20% 拖曳。
- 電腦(自動偵測,全螢幕版型):WASD / 方向鍵移動;選角畫面用滑鼠點選,或 ←→ 換角色、↑↓ 換武器、D 換難度、Enter 開始、T 開成就;升級時滑鼠點卡片或按 1/2/3、R 重抽;Q/E 調速、P 暫停、M 靜音、F 切換瀏覽器全螢幕。

## 部署
直接部署到 Cloudflare Pages 或 GitHub Pages(根目錄即可)。
