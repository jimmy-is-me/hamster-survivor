# 🐹 倉鼠球大冒險 Hamster Survivor

可愛風單指割草 Roguelike(HTML5 Canvas,純靜態,無需建置)。

## 檔案結構
- `index.html`:頁面與選單結構
- `style.css`:樣式
- `game.js`:遊戲邏輯

## 內容
- 8 位角色(倉鼠、兔兔、熊熊、小貓、狐狸、青蛙、企鵝、獨角獸)
- 9 種武器 + 6 種被動,升級三選一
- 3 場 Boss 戰:60 秒巨無霸甜甜圈、120 秒蛋糕女王、170 秒草莓聖代(三階段)
- 特殊掉落物:💖愛心、🧲全場磁鐵、💣炸彈、❄️冰凍、🛡️無敵、⭐超級經驗、🎁Boss 寶箱(免費天賦)

## 操作
手機:按住畫面下方 20% 拖曳。電腦:滑鼠拖曳下方區域,或 WASD / 方向鍵。

## 部署
直接部署到 Cloudflare Pages 或 GitHub Pages(根目錄即可)。
